## 초록 (Abstract)

PreNorm을 사용하는 잔차 연결(Residual Connection)은 현대 LLM의 표준이지만, 모든 레이어 출력을 **고정된 단위 가중치**로 누적한다. 이 균일한 집계는 깊이에 따라 은닉 상태의 크기가 제어 없이 증가하고, 각 레이어의 기여가 점진적으로 희석되는 문제를 야기한다.

본 논문은 **Attention Residuals(AttnRes)**을 제안한다. 이전 레이어 출력에 대한 소프트맥스 어텐션으로 고정 누적을 대체하여, 각 레이어가 학습된 입력 의존 가중치로 이전 표현을 **선택적으로 집계**할 수 있게 한다. 대규모 훈련의 메모리 오버헤드를 해결하기 위해 **Block AttnRes**를 도입하여, 레이어를 블록으로 분할하고 블록 수준 표현에 대해 어텐션을 수행한다.

**Kimi Linear 아키텍처(48B/3B 파라미터)**에 통합하여 1.4T 토큰으로 사전 훈련한 결과, 모든 평가 작업에서 성능이 향상되었다.

## 1. 서론 (Introduction)

표준 잔차 연결 $h\_l = h\_{l-1} + f\_{l-1}(h\_{l-1})$은 그래디언트 하이웨이로서 안정적인 깊은 학습을 가능하게 한다. 그러나 이 잔차는 **깊이 방향 정보 집계**라는 두 번째 역할도 수행한다. 순환을 풀어보면:

$$h\_l = h\_1 + \sum\_{i=1}^{l-1} f\_i(h\_i)$$

모든 레이어가 동일한 균일 가중치 합을 받는다. 시퀀스 믹싱과 전문가 라우팅은 이제 학습 가능한 입력 의존 가중치를 사용하지만, 깊이 방향 집계는 여전히 **고정 단위 가중치**에 의존한다.

### PreNorm 희석 문제

PreNorm 하에서 $\|h\_l\|$은 깊이에 따라 $O(L)$로 증가한다. 이로 인해:
1. **선택적 접근 불가**: 다른 레이어 유형(어텐션 vs MLP)이 동일한 집계 상태를 받음
2. **비가역적 손실**: 집계를 통해 손실된 정보를 깊은 레이어에서 복구 불가
3. **출력 크기 증가**: 깊은 레이어가 누적된 잔차에 영향을 미치기 위해 점점 더 큰 출력을 학습

### 시간-깊이 이중성

RNN이 시간 축에서 모든 이전 정보를 단일 상태로 압축하듯, 잔차 연결은 깊이 축에서 동일한 일을 한다. Transformer가 시간 축의 순환을 어텐션으로 대체했듯이, **깊이 축의 순환도 어텐션으로 대체**할 수 있다:

$$h\_l = \alpha\_{0 \to l} \cdot h\_1 + \sum\_{i=1}^{l-1} \alpha\_{i \to l} \cdot f\_i(h\_i) \quad (1)$$

> **직관적 이해**: 시퀀스에서 각 토큰이 이전 모든 토큰을 어텐션으로 선택적 참조하듯, 각 레이어도 이전 모든 레이어 출력을 **선택적으로 참조**한다. 네트워크 깊이가 보통 1000 미만이므로 $O(L^2)$ 깊이 어텐션은 계산적으로 실현 가능하다.

### 핵심 기여

- **Attention Residuals**: 깊이 방향 소프트맥스 어텐션으로 고정 잔차 대체
- **Block AttnRes**: 메모리/통신을 $O(Ld)$에서 $O(Nd)$로 축소
- **인프라 최적화**: 크로스 스테이지 캐싱, 2단계 연산 전략 → 훈련 오버헤드 4% 미만, 추론 지연 2% 미만
- **포괄적 검증**: 스케일링 법칙, 절삭, Kimi Linear 48B에서 모든 벤치마크 향상

## 2. 동기 (Motivation)

### 2.1 잔차를 통한 심층 네트워크 학습

**잔차 학습**: 각 레이어가 $h\_l = h\_{l-1} + f\_{l-1}(h\_{l-1})$로 업데이트한다. 역전파 시 그래디언트:

$$\frac{\partial \mathcal{L}}{\partial h\_l} = \frac{\partial \mathcal{L}}{\partial h\_L} \cdot \prod\_{j=l}^{L-1}\left(I + \frac{\partial f\_j}{\partial h\_j}\right)$$

> **직관적 이해**: 전개하면 항등 항 $I$가 항상 보존되어, 깊이와 무관하게 손실에서 어느 레이어로든 직접적인 그래디언트 경로가 존재한다.

**잔차 일반화 — Highway 네트워크**:

$$h\_l = (1 - g\_l) \odot h\_{l-1} + g\_l \odot f\_{l-1}(h\_{l-1})$$

여기서 $g\_l \in [0,1]^d$가 변환과 항등 경로를 보간한다. 더 일반적으로 $h\_l = \alpha\_l \cdot h\_{l-1} + \beta\_l \cdot f\_{l-1}(h\_{l-1})$의 가중 순환이다.

### 한계

고정이든 게이트든, 모든 접근법은 **근본적 제약**을 공유한다: 각 레이어가 직전 입력 $h\_{l-1}$만 접근 가능하며, 이는 모든 이전 출력을 혼합한 단일 압축 상태이다.

```
표준 잔차의 정보 흐름:

레이어 1: h₁ = embedding
레이어 2: h₂ = h₁ + f₁(h₁)           ← h₁에만 접근
레이어 3: h₃ = h₂ + f₂(h₂)           ← h₁+f₁의 혼합물에만 접근
레이어 4: h₄ = h₃ + f₃(h₃)           ← h₁+f₁+f₂의 혼합물에만 접근
          ↑
    f₁의 개별 출력을 선택적으로 꺼낼 수 없음!
```

## 3. Attention Residuals: 시간과 깊이의 통합 관점

### 3.1 Full Attention Residuals

어텐션 가중치를 $\alpha\_{i \to l} = \phi(q\_l, k\_i)$로 쓸 수 있으며, 커널 $\phi(q, k) = \exp(q^\top \text{RMSNorm}(k))$와 정규화:

$$\alpha\_{i \to l} = \frac{\phi(q\_l, k\_i)}{\sum\_{j=0}^{l-1} \phi(q\_l, k\_j)} \quad (2)$$

각 레이어 $l$에 대해:

$$q\_l = w\_l, \quad k\_i = v\_i = \begin{cases} h\_1 & i=0 \\ f\_i(h\_i) & 1 \le i \le l-1 \end{cases} \quad (3)$$

여기서 $w\_l \in \mathbb{R}^d$는 **레이어별 학습 가능 의사 쿼리(pseudo-query)** 벡터이다. RMSNorm은 큰 크기의 출력이 어텐션 가중치를 지배하는 것을 방지한다. 레이어 $l$의 입력:

$$h\_l = \sum\_{i=0}^{l-1} \alpha\_{i \to l} \cdot v\_i \quad (4)$$

> **직관적 이해**: 각 레이어가 $d$차원 벡터 하나($w\_l$)만으로 "이전 레이어들 중 어디를 볼까?"를 결정한다. RMSNorm이 키에 적용되어, 출력 크기가 큰 레이어가 자동으로 유리해지는 것을 방지한다.

**오버헤드**: $O(L^2 d)$ 연산, $O(Ld)$ 메모리. 바닐라 훈련에서 역전파를 위해 이미 활성값을 저장하므로 **추가 메모리 오버헤드 없음**. 그러나 대규모 훈련에서 활성값 재계산 + 파이프라인 병렬처리 시 문제 발생.

### 3.2 Block Attention Residuals

$L$개 레이어를 $N$개 블록으로 분할한다. **블록 내부**에서는 표준 잔차 누적, **블록 간**에는 소프트맥스 어텐션을 적용한다.

<div class="mermaid">
graph TB
    subgraph "Block AttnRes 구조"
        direction TB
        EMB["임베딩 b₀ = h₁"]
        subgraph B1["블록 1"]
            L1["Attn"] --> L2["MLP"]
            L2 --> L3["Attn"] --> L4["MLP"]
        end
        subgraph B2["블록 2"]
            L5["Attn"] --> L6["MLP"]
            L6 --> L7["Attn"] --> L8["MLP"]
        end
        EMB -->|"어텐션"| B1
        EMB -->|"어텐션"| B2
        B1 -->|"b₁ = Σ출력"| ATTN2["블록간 어텐션"]
        EMB -->|"b₀"| ATTN2
        ATTN2 --> B2
    end
</div>

#### 블록 내 누적

$S = L/N$ 레이어를 각 블록에 배치하고, 블록 출력을 합산:

$$b\_n = \sum\_{j \in B\_n} f\_j(h\_j) \quad (5)$$

#### 블록 간 어텐션

블록 $n$의 $i$번째 레이어에 대한 값 행렬:

$$V = \begin{cases} [b\_0, b\_1, \ldots, b\_{n-1}]^\top & i = 1 \text{ (블록 첫 레이어)} \\ [b\_0, b\_1, \ldots, b\_{n-1}, b\_n^{i-1}]^\top & i \ge 2 \text{ (이후 레이어)} \end{cases} \quad (6)$$

> **직관적 이해**: 블록의 첫 레이어는 이전 완성 블록들만 참조하고, 이후 레이어는 현재 블록의 부분합도 추가로 참조한다. $N \approx 8$이면 대부분의 이점을 회수하면서 8개의 은닉 상태만 저장하면 된다.

**효율성 비교:**

| 설정 | 메모리 | 연산 |
|------|:------:|:----:|
| Full AttnRes | $O(Ld)$ | $O(L^2d)$ |
| **Block AttnRes** | $O(Nd)$ | $O(N^2d)$ |
| $N=1$ | 표준 잔차와 동일 | — |
| $N=L$ | Full AttnRes와 동일 | — |

#### 구현 의사코드 (PyTorch)

```python
def block_attn_res(blocks, partial_block, proj, norm):
    """블록간 어텐션: 이전 블록들 + 부분합에 대해 어텐션"""
    V = torch.stack(blocks + [partial_block])     # [N+1, B, T, D]
    K = norm(V)                                    # RMSNorm
    logits = einsum('d, n b t d -> n b t', proj.weight, K)
    h = einsum('n b t, n b t d -> b t d', logits.softmax(0), V)
    return h
```

## 4. 인프라 최적화

### 4.1 훈련

소규모 훈련에서 AttnRes는 미미한 연산 오버헤드만 추가하며, 역전파용 활성값이 이미 저장되므로 추가 메모리 불필요. 대규모에서는 **파이프라인 병렬처리**가 주요 과제이다.

#### 크로스 스테이지 캐싱

$P$개 물리 스테이지, 스테이지당 $V$개 가상 스테이지의 인터리브 파이프라인. 나이브 구현 통신 비용:

$$\text{Comm}\_{\text{naïve}} = \frac{C(C-1)}{2}N\_p d \quad (7)$$

캐싱 적용 시:

$$\text{Comm}\_{\text{cached}} = \underbrace{\frac{P(P-1)}{2}N\_p d}\_{\text{첫 번째 가상 스테이지}} + \underbrace{(V-1)P^2 N\_p d}\_{\text{이후 가상 스테이지}} \quad (8)$$

> **직관적 이해**: 각 물리 스테이지가 여러 가상 스테이지를 순차 처리하므로, 이전에 받은 블록을 로컬 메모리에 캐싱하면 재전송이 불필요하다. 피크 전송 비용이 $O(C)$에서 $O(P)$로 **$V$배 개선**된다.

**메모리 오버헤드**: 파이프라인 미사용 시 무시 가능, 파이프라인 사용 시 종단간 오버헤드 **4% 미만**.

### 4.2 추론

#### 2단계 연산 전략 (Algorithm 1)

의사 쿼리 $w\_l$이 순방향 연산과 독립적이므로, 블록 내 모든 $S$개 쿼리를 단일 행렬 곱으로 배치 처리 가능.

- **1단계 (병렬)**: 블록 내 모든 $S$개 레이어의 블록간 어텐션을 동시 계산. 소프트맥스 통계(max, log-sum-exp) 반환.
- **2단계 (순차)**: 각 레이어의 블록내 어텐션을 순차 계산 후, **온라인 소프트맥스**로 1단계 결과와 병합.

<div class="mermaid">
graph LR
    subgraph "1단계: 병렬"
        Q["쿼리 w₁...w_S"] --> MAT["배치 행렬곱"]
        BLK["블록 b₀...b_{n-1}"] --> MAT
        MAT --> OUT1["출력 + LSE 통계"]
    end
    subgraph "2단계: 순차"
        OUT1 --> MERGE["온라인 소프트맥스 병합"]
        INTRA["블록내 부분합"] --> MERGE
        MERGE --> FINAL["최종 h_l"]
    end
</div>

#### 메모리 접근 비용 비교 (Table 1)

| 방법 | 읽기 | 쓰기 | 총 I/O | 일반적 값 |
|------|:----:|:----:|:------:|:--------:|
| 표준 잔차 | $2d$ | $d$ | $3d$ | $3d$ |
| mHC ($m=4$) | 복잡 | 복잡 | $(8m+2)d + \ldots$ | $34d$ |
| Full AttnRes | $(S+N)d$ | $2d$ | $(S+N+2)d$ | $24d$ |
| **Block AttnRes** | $(\frac{N}{S}+3)d$ | $d$ | $(\frac{N}{S}+5)d$ | **$5.5d$** |

> **직관적 이해**: Block AttnRes는 표준 잔차($3d$)보다 약간 많은 $5.5d$의 I/O만 필요하면서, mHC($34d$)보다 6배 이상 효율적이다.

**추론 지연 오버헤드**: 일반적인 워크로드에서 **2% 미만**.

#### 메모리 효율 프리필

128K 토큰 시퀀스에서 블록 표현 저장에 15GB 필요. $P$개 텐서 병렬 디바이스에 시퀀스 차원으로 샤딩하여 디바이스당 $N \cdot (T/P) \cdot d$로 축소. 청크 프리필(16K 청크)과 결합하면 디바이스당 **0.3GB 미만**.

## 5. 실험 (Experiments)

**아키텍처**: Kimi Linear (Moonlight/DeepSeek-V3 설계). KDA와 MLA 레이어를 3:1로 교대 배치. AttnRes만 추가하고 나머지(깊이, 차원, 라우팅, MLP)는 변경 없음.

**초기화**: 모든 의사 쿼리 $w\_l$은 **반드시 0으로 초기화**. 이렇게 하면 초기에 균일 가중치가 되어 표준 잔차의 균등 평균으로 시작하며, 훈련 안정성이 보장된다.

### 5.1 스케일링 법칙

5개 모델 크기에서 3가지 변형(Baseline, Full AttnRes, Block AttnRes)을 8192 토큰 컨텍스트로 훈련.

어텐션 가중치 $\alpha\_{i \to l}$ 히트맵에서 세 가지 관찰:

1. **보존된 지역성**: 각 레이어가 직전 레이어에 가장 강하게 어텐션, 그러나 선택적 원거리 집중도 존재
2. **레이어 전문화**: 임베딩 $h\_1$이 전체에 걸쳐 비자명 가중치 유지. Pre-MLP는 최근 표현에 날카롭게 의존, Pre-Attention은 더 넓은 수용장
3. **Block AttnRes 구조 보존**: 대각 우세, 임베딩 지속, 레이어 전문화가 Full에서 Block으로 전이

## 6. 논의 (Discussions)

### 6.1 시퀀스-깊이 이중성

잔차 연결은 깊이 축에서 고정 순환 $h\_l = h\_{l-1} + f\_{l-1}(h\_{l-1})$으로 정보를 전파한다. TTT(Test-Time Training)는 시퀀스 측에서 이를 경사 하강법으로 형식화:

$$W\_t = W\_{t-1} - \eta \nabla \ell(W\_{t-1}; x\_t) \quad (9)$$

$f$가 선형이면 바닐라 선형 어텐션 $S\_t = S\_{t-1} + k\_t v\_t^\top$으로 축소된다. 표준 잔차도 동일한 가법 형태.

이 이중성은 더 풍부한 변형으로 확장된다:
- 시퀀스: 데이터 의존 게이트 → 깊이: Highway 네트워크
- 시퀀스: 델타 규칙 → 깊이: DDL
- 시퀀스: GLA → 깊이: MRLA

**AttnRes는 한 발 더 나아가** 깊이 순환을 직접적인 교차 레이어 어텐션으로 대체한다 — Transformer가 시간 순환을 self-attention으로 대체한 것과 동일하다.

### 6.2 잔차 연결의 구조화 행렬 관점

모든 잔차 변형은 깊이 믹싱 행렬 $M \in \mathbb{R}^{L \times L}$로 볼 수 있다:

$$h\_l = \sum\_{i=0}^{l-1} M\_{i \to l} \cdot v\_i$$

| 방법 | 가중치 유형 | 소스 접근 | $M$의 구조 |
|------|:--------:|:-------:|:--------:|
| 표준 잔차 | 고정 (=1) | $h\_{l-1}$ | 전체 1 하삼각 |
| Highway | 동적 (게이트) | $h\_{l-1}$ | 1-반분리 |
| (m)HC | 동적 ($m$스트림) | $m$ 스트림 | $m$-반분리 |
| **Full AttnRes** | 동적 (softmax) | 모든 이전 | 밀집, 랭크-$L$ |
| **Block AttnRes** | 동적 (softmax) | 블록 수준 | 랭크 $N$~$N+S$ |

> **직관적 이해**: 기존 잔차 변형은 깊이 방향 **선형 어텐션**에 해당하고, AttnRes는 깊이 방향 **소프트맥스 어텐션**에 해당한다. 시퀀스 차원에서 선형→소프트맥스 전환이 혁신적이었듯, 깊이 차원에서도 동일한 전환을 완성한다.

## 7. 관련 연구 (Related Work)

### 정규화, 스케일링, 깊이 안정성

PostNorm은 크기를 유지하지만 그래디언트를 왜곡하고, PreNorm은 깨끗한 항등 경로를 복원하지만 $O(L)$ 크기 증가를 도입한다. AttnRes는 개별 이전 레이어 출력에 대한 선택적 집계로 가법 순환을 대체하여, PreNorm의 누적 크기 증가와 PostNorm의 스케일 수축 모두를 회피한다.

### 다중 상태 순환

Hyper-Connections, mHC, DDL, SiameseNorm 등이 순환을 다중 병렬 스트림으로 확장. AttnRes는 이들과 직교적이며, 개별 이전 레이어 출력에 대한 선택적 접근을 제공하면서 어떤 정규화/게이팅 방식과도 호환 가능.

### 교차 레이어 연결

DenseNet, ELMo, DenseFormer, MUDDFormer, MRLA 등. AttnRes는 소프트맥스 정규화된 입력 의존 가중치와 모든 이전 레이어에 대한 선택적 접근을 단일 $d$차원 의사 쿼리로 결합하며, 블록 구조로 비용을 $O(L^2)$에서 $O(LN)$으로 축소한다.

**방법론 비교 (Table 5):**

| 범주 | 방법 | 가중치 | 소스 |
|------|------|:------:|:----:|
| **단일 상태** | Residual | 고정 | $h\_{l-1}$ |
| | ReZero | 정적 | $h\_{l-1}$ |
| | Highway | 동적 | $h\_{l-1}$ |
| | DeepNorm | 고정 | $h\_{l-1}$ |
| **다중 상태** | SiameseNorm | 고정 | 2 스트림 |
| | HC/mHC | 동적 | $m$ 스트림 |
| | DDL | 동적 | $d\_v$ 스트림 |
| **교차 레이어** | DenseFormer | 정적 | 모든 이전 |
| | MRLA | 동적 | 모든 이전 |
| | **AttnRes (ours)** | **동적** | **모든 이전** |

## 결론 (Conclusion)

시퀀스와 깊이의 이중성에서 영감을 받아, 고정된 균일 잔차 누적을 **학습된 입력 의존 깊이 방향 어텐션**으로 대체하는 AttnRes를 제안했다. Full AttnRes의 $O(Ld)$ 메모리를 Block AttnRes로 $O(Nd)$로 축소하여 대규모 모델에서 실용적으로 사용 가능하다.

약 **8개 블록**으로 Full AttnRes의 대부분의 이점을 회수하며, 크로스 스테이지 캐싱과 2단계 연산 전략으로 훈련 오버헤드 4% 미만, 추론 오버헤드 2% 미만을 달성한다.

## 부록 B: Full AttnRes 최적화 추론 I/O

### 2단계 스케줄 유도

$L$개 레이어, $N$개 블록, 블록 크기 $S = L/N$.

**1단계 (블록간 어텐션)**: 블록 $n$의 읽기 비용:

$$\text{Read}^{(n)}\_{\text{inter}} = 2(n-1)Sd \quad (11)$$

전체 합산:

$$\text{Read}\_{\text{inter}} = dL(N-1) \quad (12)$$

**2단계 (블록내 어텐션)**: 블록 내 레이어 $t$의 읽기 비용:

$$\text{Read}^{(n)}\_{\text{intra}} = S(S-1)d \quad (14)$$

**총 레이어당 분할 I/O**:

$$\text{Read per layer} = (N-1)d + (S-1)d = (S+N-2)d$$

$$\text{Total I/O per layer} = (S+N)d \quad (17)$$

> **직관적 이해**: 배치 처리가 블록간 읽기를 $S$회에서 1회로 분할 상환하여, 레이어당 I/O를 $O(L)$에서 $O(S+N)$으로 줄인다.
